# Next.js 15 주요변경 사항

## 1. React 19 공식 지원
  - 변경 내용: Next.js 15은 React 19를 공식적으로 지원
  - 장점: React 19의 새로운 기능과 성능 향상을 활용
  - 단점: React 19로의 업그레이드 시 일부 호환성 문제가 발생 가능

## 2. 비동기 요청 API 변경 (Breaking Change)
  - 변경 내용: `headers`, `cookies`, `params`, `searchParams`와 같은 요청 관련 API가 비동기 방식으로 변경
  - 장점: 서버 컴포넌트의 사전 렌더링 최적화에 도움
  - 단점: 기존 동기 코드를 비동기 방식으로 수정해야 하므로 코드 변경 필요

## 3. 캐싱 기본값 변경
  - 변경 내용: `fetch`요청, `GET`라우트 핸들러, 클라이언트 라우터 캐시의 기본 캐싱 동작 변경. 이전에는 기본적으로 캐싱이 되었으나, 이제는 기본적으로 캐시되지 않음.
  - 장점: 최신 데이터를 더 쉽게 가져올 수 있음.
  - 단점: 필요한 경우 명시적으로 캐싱을 설정해야 하므로 추가 설정 필요.

## 4. Turbopack 개발 모드 안정화
  - 변경 내용: `next dev --turbo` 명령어가 안정화되어 개발 환경에서 사용 가능
  - 장점: 개발 서버 시작 시간 단축, 코드 변경 시 빠른 반영 등 개발 경험 향상
  - 단점: 일부 프로젝트에서 설정이나 호환문제 가능성 있음

## 5. 정적 경로 표시기 추가
  - 변경 내용: 개발 모드에서 정적 경로를 시각적으로 표시해주는 기능 추가
  - 장점: 어떤 경로가 정적으로 렌더링되는지 쉽게 파악 가능
  - 단점: 일부 개발자들에겐 불필요한 정보로 느껴질 수 있음

## 6. React Compiler 지원 (실험적 기능)
  - 변경 내용: 리액트팀에서 새발한 새로운 컴파일러를 실험적으로 지원
  - 장점: 코드 최적화를 자동으로 수행하여 성능 향상과 코드 유지보수성에 개선에 도움
  - 단점: 현재 실험적 단계로 안정성이 떨어질 수 있음

## 7. Hydration 오류 개선
  - 변경 내용: Hydration 오류 발생 시 소스 코드를 표시하고 수정 방법을 제안하는 기능 추가
  - 장점: 디버깅이 용이해져 개발 생산성 향상
  - 단점: 일부 복잡한 오류의 경우 충분한 정보 제공을 하지 못할 수 있음
